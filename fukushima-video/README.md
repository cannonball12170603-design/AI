# 福島県 名所紹介動画プロジェクト

## 企画概要

| 項目 | 内容 |
|---|---|
| テーマ | 福島県の名所紹介 |
| 尺 | 約60秒 |
| フォーマット | 縦型 9:16（TikTok / YouTube Shorts / Instagram リール想定） |
| 出演 | なし（案内役キャラクターを置かず、ナレーション＋名所映像で構成） |
| 演出コンセプト | 明るく元気なテンション、カット割りの速いテンポ紹介動画 |
| 紹介スポット | 鶴ヶ城（会津若松城）／大内宿／五色沼（裏磐梯）／猪苗代湖／あぶくま洞／花見山公園／スパリゾートハワイアンズ　計7箇所 |

> 注記：当初は案内役の少女キャラクターを実写風に登場させる案でしたが、実在の子どもの写真を
> AIキャラクター生成の参照に使うことは行えないため、人物なし（名所映像＋ナレーション＋テロップ）
> の構成に変更しました。

## 進行状況

- [x] 台本作成（`script.md`）
- [x] カット割り／絵コンテ作成（`storyboard.md`）
- [ ] Higgsfieldでの名所風景素材生成（画像・動画）
- [ ] 各カットの映像素材生成
- [ ] 素材の書き出し・編集用まとめ

## 次のステップ（Higgsfield連携）

1. `storyboard.md` の各カットのプロンプトを元に、名所の風景映像を `generate_video`（text-to-video）で生成
2. 生成した素材を `assets/` 配下にカットNo.ごとに整理
3. 必要に応じて `upscale_video` / `reframe` などで縦型9:16に最終調整
4. ナレーションは別途TTSまたは収録音声を編集時に合成

## ファイル構成

- `script.md` … ナレーション・セリフの決定稿
- `storyboard.md` … カット割り表（秒数・画角・演技・テロップ・Higgsfield生成メモ）
- `assets/` … 生成素材の格納先（今後追加）
