## 次のステップ（Higgsfield連携）

案内役の少女の写真がアップロードされ次第、以下の順で素材を揃えます。

1. アップロード写真から Higgsfield にキャラクター参照を登録
2. `storyboard.md` の各カットのプロンプトを元に、キャラクター一貫性を保った画像・動画を生成
   - 人物が写らない風景カット（鶴ヶ城の遠景など）は先行して素材化可能
3. 生成した素材を `assets/` 配下にカットNo.ごとに整理
4. 必要に応じて `upscale_video` / `reframe` などで縦型9:16に最終調整

- `assets/` … 生成素材の格納先（今後追加）
